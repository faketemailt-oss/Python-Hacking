# Security Policy

## Scope

Report security issues affecting authentication, enrollment, authorization, credential handling, data exposure, or unsafe telemetry collection.

## Responsible disclosure

Do not publish sensitive vulnerability details before maintainers have had a reasonable opportunity to investigate. Use a private GitHub security advisory when available; otherwise contact the maintainer privately through GitHub.

Never include real device credentials, bot tokens, private keys, or personal telemetry in an issue.

## Security principles

- explicit device enrollment
- revocation
- least-privilege telemetry
- server-side secret handling
- bounded local storage
- authenticated reporting
- privacy-preserving logs
